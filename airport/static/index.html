NEED A HAND?

常见问题

提示“VoWLAN 鉴权失败”

先核对控制端口。443 可能是 NAS 网页登录入口。确认 iPhone 与目标安卓已完成 VoWLAN 配对；网页登录密码与 AirSIM 配对凭据是两回事。airport 不修改安卓协议，也不能代替手机完成身份验证。

能保存，但通话没有声音

检查音频公网端口是否映射到 NAS 的 TLS 音频入口；NAS 再转发到安卓的原始 PCM 端口。普通 HTTP 网页反向代理无法转发 PCM，需要本工具这样的 TCP TLS 转发。还要核对安卓音频桥和权限。

域名可以打开，为什么还是连不上？

浏览器打开域名只证明网页端口可用。AirSIM 需要独立的控制、音频入口和有效证书。Cloudflare 等 DNS 服务应使用“仅 DNS”，不要给这两个原始 TCP 入口开启普通网页 CDN 代理。

安卓重启之后连不上

为安卓设置 DHCP 地址保留。安卓端口被占用时可能自动选择其他端口，请核对实际控制和 PCM 端口后更新配置并应用。

需要把配对端口开放到公网吗？

不需要。配对在局域网完成，只开放控制和音频两路 TLS 入口。不要把管理面板、配对端口或安卓的原始明文端口映射到公网。

证书如何续期？

通过 DNS 申请的证书会自动续期；挂载证书会每分钟检测 NAS 更新；手动上传的证书需要重新上传。面板会展示剩余天数。修改域名后要重新申请或导入对应证书。
